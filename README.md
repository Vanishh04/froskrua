# FROSKRUA

Односторінковий сайт тренерки: гімнастика онлайн для дітей 5–16 років.  
Стек: HTML, CSS, звичайний JavaScript. Збірка і npm не потрібні.

Відкрийте `index.html` у браузері або завантажте теку на Netlify чи GitHub Pages.

## Як швидко правити сайт

Майже весь текст живе в одному файлі: [`js/content.js`](js/content.js).  
Після збереження оновіть сторінку. HTML для заголовків, цін і кнопок чіпати не потрібно.

Кольори, шрифт, відступи, радіуси і тіні — у блоці `:root` на початку [`css/style.css`](css/style.css).

### 1. Заголовки й описи

У `js/content.js`:

- перший екран — `hero.title`, `hero.lead`, `hero.kicker`
- підхід — `approach.title`, `approach.text`, `approach.items`
- хід тренування — `process.title`, `process.steps`
- про Фросю — `about.title`, `about.paragraphs`
- фінальний заклик — `finalCta.title`, `finalCta.text`

Слово з `hero.titleAccent` стає рожевим курсивом, якщо воно є в заголовку.

### 2. Ціни

У масиві `services` знайдіть картку і змініть:

- `price` — число або короткий текст, наприклад `"800"`
- `currency` — `"грн"` (показується лише коли ціна заповнена)
- `priceNote` — підпис на кшталт `"за заняття"`
- `duration` — наприклад `"45 хвилин"`

Порожній `price` або `duration` на сайті виглядає як **Уточнюється**. Це навмисно: ціну не вигадано.

### 3. Додати або прибрати формат

У `services` уже є прихований шаблон (`hidden: true`).

- Показати картку: `hidden: false`, перейменуйте її під реальну послугу.
- Сховати: `hidden: true` або видаліть об’єкт.
- Зробити картку головною: `featured: true` лише в однієї. Решті поставте `false`.
- Пункти «що входить» — масив `includes`.
- Текст кнопки — `cta`. Усі кнопки запису відкривають один і той самий Telegram.

Не вмикайте шаблон, якщо такого формату ще немає.

### 4. Замінити фото

1. Покладіть файл у `assets/images/` (для відео — `assets/videos/`).
2. У `images` впишіть шлях:

```js
hero: "assets/images/hero.jpg",
heroAlt: "Опис фото українською",
about: "assets/images/about.jpg",
aboutAlt: "Фрося на тренуванні",
```

Порожній рядок лишає графічний постер. Не ставте чуже фото і не пишіть в alt, що це Фрося, якщо на знімку не вона.

Додаткові кадри — масив `images.gallery`:

```js
{ src: "assets/images/training-1.jpg", alt: "Тренування з гімнастики" },
```

Клік по такому фото відкриває його крупно.

### 5. Відгуки

У `testimonials.items` додайте об’єкт лише зі справжнім текстом:

```js
{
  name: "Ім’я",
  text: "Текст відгуку.",
  result: "",
  photo: "",
  image: "assets/images/reviews/review-1.jpg",
  imageAlt: "Скріншот відгуку"
},
```

Порожній масив не показує вигаданих цитат — лише посилання на актуальне «відгуки» в Instagram. Поле `result` заповнюйте тільки якщо результат справді був.

Скріншот (`image`) відкривається в лайтбоксі.

### 6. Питання і відповіді

Масив `faq.items`. Кожен пункт: `q` і `a`.  
Можна додавати і видаляти об’єкти. Перше питання відкрите. HTML у відповіді не потрібен; новий рядок у тексті стає переносом.

### 7. Telegram

Одне поле на весь сайт:

```js
links: {
  telegram: "https://t.me/username",
}
```

Його беруть герой, меню, картки цін, блок після відгуків, фінальна кнопка, підвал і кругла кнопка на телефоні.

Зараз стоїть тимчасове `https://t.me/` — замініть на реальний чат.

### 8. Instagram

```js
instagram: "https://www.instagram.com/froskrua/",
```

### 9. Кольори бренду

У `:root` у `css/style.css`:

| Змінна | Зараз | Де видна |
| --- | --- | --- |
| `--color-blue` | `#7CCFF0` | постери, смуги, фінальний блок |
| `--color-white` | `#FFFFFF` | фон і картки |
| `--color-pink` | `#FF2E93` | кнопки, акценти, активні стани |
| `--color-ink` | `#12151A` | текст |

Поруч там само: шрифт, розміри заголовків, відступи секцій, радіус карток, тіні, ширина колонки (`--content`, зараз 1520px) і швидкість анімації.

На рожевій кнопці текст темний — так він лишається читабельним. Світло-блакитний не використовується для дрібного тексту.

## Запуск локально

З теки проєкту:

```bash
python -m http.server 4173
```

Далі відкрийте `http://localhost:4173`.

## Що на сайті навмисно без вигаданих цифр

Поки немає підтвердження, на сторінці немає ціни, тривалості, кількості учнів, років стажу, освіти, міста, розкладу і чужих відгуків.

Уже стоїть те, що є в публічних джерелах бренду:

- звання з біо Instagram
- онлайн-формат і вік 5–16
- старт без спортивного досвіду
- ім’я Євфросинія Кривицька (можна лишити лише «Фрося» в `about.paragraphs`)
- профіль Instagram

На одному креативі зустрічається вік 5–12. Якщо це окрема група, поправте `brand.ageRange` і тексти, де є «5–16».

Якщо точна назва дисципліни інша (художня чи спортивна гімнастика), замініть слово «Гімнастика» в `brand.discipline` і в текстах.

## Структура

```
index.html          каркас сторінки і SEO-мета
css/style.css       вигляд, усі змінні у :root
js/content.js       тексти, ціни, посилання, шляхи до фото
js/script.js        збірка сторінки, меню, акордеон, лайтбокс
assets/images/      фото
assets/icons/       іконки і фавікон
assets/videos/      відео, якщо з’явиться
```
